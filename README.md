# TiendaIA Pro — MVP profesional

TiendaIA Pro es una app web para tiendas pequeñas y medianas en México. Está pensada para abarrotes, minisúpers, papelerías y negocios familiares que quieren controlar inventario, ventas, proveedores y recomendaciones comerciales.

## Qué incluye

- Dashboard ejecutivo con ventas, inventario y alertas.
- Inventario con SKU, código de barras, proveedor, margen y stock mínimo.
- Punto de venta básico para registrar ventas.
- Reportes por categoría y productos más vendidos.
- Copiloto de recomendaciones comerciales.
- Módulo de proveedores.
- Datos demo para enseñar el producto a clientes.

## Cómo correrlo

1. Instala Python 3.11 o superior.
2. Abre la terminal dentro de esta carpeta.
3. Ejecuta:

```bash
pip install -r requirements.txt
python seed.py
python run.py
```

4. Abre el navegador en:

```text
http://127.0.0.1:5000
```
